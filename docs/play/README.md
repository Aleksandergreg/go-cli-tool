# Play OpsQuest

OpsQuest teaches through short incidents inside disposable environments. You inspect the situation, use familiar operational tools, and complete the mission when the required outcomes are observable.

## Start here

1. [Install and launch OpsQuest](quick-start.md).
2. Learn [how missions, hints, and routes work](how-missions-work.md).
3. Keep the [controls and command reference](controls-and-commands.md) nearby while playing.

The default route follows the four [Linux worlds](linux-worlds.md). The separate [Docker Foundations](docker-foundations.md) track is optional and never blocks Linux progress.

## What carries between sessions

Your XP, rank, mission completions, practiced commands, hint progress, and achievements are stored in a local profile. The virtual filesystem and processes belong only to the current mission attempt and are discarded when that attempt ends or restarts.

See [Progression and rewards](../game/progression.md) for the complete progression model.
